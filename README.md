# Скорость интернета

Консольная утилита на Python измеряет скорость скачивания указанного ресурса. Она выполняет 10 последовательных HTTP(S)-запросов, полностью читает каждый ответ и выводит среднее время запроса, общий объём данных и скорость скачивания.

## Требования

- Python 3.8 или новее
- сторонние зависимости не нужны

## Запуск

```bash
python3 speedtest.py "https://speed.hetzner.de/10MB.bin"
```

Вместо адреса из примера можно передать URL любого файла. Для заметного и стабильного результата лучше использовать файл размером от нескольких мегабайт.

Пример вывода:

```text
Запрос 1/10: 0.812 с, 10 000 000 байт
...
Запрос 10/10: 0.765 с, 10 000 000 байт

Среднее время запроса: 0.789 с
Всего скачано: 100.00 МБ (100 000 000 байт)
Скорость скачивания: 101.40 Мбит/с
```

## Как считаются показатели

- **Среднее время запроса** — суммарное время всех запросов, делённое на 10. Время включает получение заголовков и полное чтение тела ответа.
- **Всего скачано** — сумма фактически прочитанных байт всех ответов.
- **Скорость скачивания** — `общий объём в битах / суммарное время запросов`.

Единицы измерения десятичные: **1 МБ = 1 000 000 байт**, **1 Мбит/с = 1 000 000 бит/с**.

Если запрос завершился ошибкой, выполнение останавливается, а утилита выводит причину и возвращает ненулевой код завершения.
